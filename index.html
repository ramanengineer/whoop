Connect your WHOOP data

This dashboard pulls your real data directly from the WHOOP v2 API. It needs a personal access token — nothing is sent anywhere except WHOOP's own servers from your browser.

  1. Go to the WHOOP Developer Dashboard and create an app.
  2. Add scopes: read:recovery read:sleep read:cycles read:workout read:profile read:body_measurement
  3. Run the OAuth flow to get an access token, then paste it below.
Token stays in this page's memory only — it is never stored or transmitted to anyone but api.prod.whoop.com.
